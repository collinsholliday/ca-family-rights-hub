# CA Family Rights Hub

Independent California-focused educational resource for child support, custody and parenting time, court preparation, and inheritance questions involving unpaid child support.

## Run locally
Open `index.html` in a browser. This is a static, dependency-free site.

## Deployment
Designed for Vercel static hosting. The canonical URL and Google Search Console verification meta tag are included in `index.html`.

## Scope and safeguards
- Independent educational resource; not a government agency, court, law firm, or bar association.
- General information only, not legal advice; no attorney-client relationship.
- No accounts, payment processing, sensitive-data collection, or backend are implemented.
- Membership checkout is explicitly marked as not active.
- Attorney discovery links point to official State Bar resources rather than unverified endorsements.
- Inheritance and unpaid-support content does not promise recovery from an estate or beneficiary; individual probate and support facts require qualified legal advice.

## Official reference starting points
- https://selfhelp.courts.ca.gov/
- https://childsupport.ca.gov/
- https://www.calbar.ca.gov/public/find-legal-professionals
